# 포근 — 새로운 가족을 만나는 곳

유기견과 유기묘가 새 가족을 만날 수 있도록 만든 반응형 입양 홈페이지 시안입니다. 반려동물의 품종·나이·지역 정보를 살펴보고, 입양 상담 신청 화면을 체험할 수 있습니다.

> **시안 안내:** 현재 등록된 동물, 보호소 이름과 사진은 화면 미리보기를 위한 예시입니다. 실제 보호소 공고나 입양 가능 여부와 연동되어 있지 않습니다. 상담 신청도 시연용으로, 입력 정보가 전송되거나 저장되지 않습니다.

## 주요 기능

- 강아지·고양이 입양 프로필과 사진 표시
- 동물 종류와 지역별 필터링
- 이름·품종·지역·보호소 검색
- 나이순 정렬 및 관심 동물 찜하기
- 동물별 입양 상담 모달과 필수 입력값 검증
- 데스크톱과 모바일 화면에 대응하는 반응형 디자인
- 입양 절차 안내와 자주 묻는 질문
- 키보드 탐색을 위한 본문 건너뛰기 링크와 접근 가능한 입력 레이블

## 실행 방법

별도 빌드나 패키지 설치 없이 실행할 수 있습니다.

1. 저장소를 내려받거나 복제합니다.
2. `index.html`을 웹 브라우저에서 엽니다.

또는 프로젝트 폴더에서 간단한 로컬 서버를 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000>으로 접속합니다.

## 파일 구성

```text
adoption-website/
├── index.html   # 페이지 구조, 메타 정보, 입양 안내 및 신청 폼
├── style.css    # 색상, 레이아웃, 반응형 스타일
├── script.js    # 예시 동물 데이터, 검색·필터 및 화면 상호작용
├── robots.txt   # 협조적인 크롤러에 사이트 페이지 접근 허용을 알리는 규칙
├── sitemap.xml  # 크롤러에 사이트의 대표 URL을 안내하는 사이트맵
└── README.md    # 프로젝트 설명과 실행 방법
```

`robots.txt`는 `https://<도메인>/robots.txt`, 사이트맵은 `https://<도메인>/sitemap.xml` 경로에서 제공되어야 합니다. 현재 두 파일에는 배포 도메인 자리표시자 `example.com`이 들어 있으므로, 실제 공개 도메인에 배포하기 전에 `robots.txt`와 `sitemap.xml`에서 반드시 실제 도메인으로 바꿔 주세요. GitHub Pages는 현재 저장소에서 활성화되어 있지 않으므로 실제 서비스 주소가 아직 설정되지 않았습니다. `robots.txt`는 공개 사이트의 크롤링 안내일 뿐이며 접근을 강제하거나 제한하는 보안 수단은 아닙니다.

## 기술 스택

- HTML5
- CSS3 (Grid, Flexbox, 반응형 미디어 쿼리)
- Vanilla JavaScript (별도 라이브러리 없이 동작)
- Google Fonts: DM Sans, Noto Sans KR
- 동물 예시 이미지: Unsplash 원격 이미지

## 실제 입양 서비스로 확장할 때

- 신뢰할 수 있는 공공 동물보호·보호소 데이터 API를 연결하고 공고 정보를 최신 상태로 관리합니다.
- 보호소별 위치, 연락처, 입양 조건 및 공고 출처를 정확하게 표시합니다.
- 상담 신청을 안전하게 저장·전달할 백엔드, 접근 통제 및 개인정보 처리 절차를 마련합니다.
- 서버 측 입력 검증, 오류 처리, 개인정보 보관·삭제 기준과 개인정보 처리방침을 적용합니다.
- 외부 이미지 사용 조건과 이미지 대체 텍스트를 점검합니다.

## 라이선스 및 주의사항

이 저장소는 홈페이지 제작·학습을 위한 시안입니다. 이 사이트만으로 실제 입양 신청이 접수되거나 보호소와 상담이 연결되지는 않습니다. 실제 입양을 원하시면 관할 보호소나 동물보호 담당 기관을 통해 최신 공고와 신청 절차를 확인해 주세요.
