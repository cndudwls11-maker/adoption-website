# 포근 — 새로운 가족을 만나는 곳

유기견과 유기묘가 새 가족을 만날 수 있도록 만든 반응형 입양 홈페이지입니다. 반려동물의 품종·나이·지역 정보를 살펴보고, 입양 문의 게시판에서 질문을 작성할 수 있습니다. 로컬 개발용 SQLite 데이터베이스와 문의 게시글 테이블을 포함합니다.

> **데모 및 데이터 안내:** 동물·보호소 정보와 기본 게시글은 예시입니다. 문의 게시판은 브라우저 `localStorage`를 사용하며 SQLite에 자동 저장되지 않습니다. SQLite DB는 별도 백엔드 연결 전의 로컬 데이터베이스 초기 단계입니다.

## 주요 기능

- 강아지·고양이 입양 프로필과 사진 표시
- 동물 종류와 지역별 필터링
- 이름·품종·지역·보호소 검색
- 나이순 정렬
- 관심 있는 동물 카드에서 해당 동물의 문의 글 작성으로 바로 이동
- 입양 문의 게시판: 글 작성, 목록·상세 보기, 검색, 분류 필터, 작성자 글 삭제
- HTML·CSS만으로 구현한 회원가입·로그인 화면 시안
- 회원가입 화면에는 닉네임, 이메일, 성별, 집 주소와 비밀번호 입력란이 있습니다. 실제 회원 정보는 저장·전송되지 않습니다.
- 현재 브라우저 게시판의 글 저장은 브라우저 `localStorage`를 이용하는 시연 기능입니다. SQLite를 사용하려면 별도 서버 API 연동이 필요합니다.
- 데스크톱과 모바일 화면에 대응하는 반응형 디자인
- 입양 절차 안내와 자주 묻는 질문
- 키보드 탐색을 위한 본문 건너뛰기 링크와 접근 가능한 입력 레이블

## 실행 방법

별도 빌드나 패키지 설치 없이 정적 페이지를 확인할 수 있습니다. SQLite 초기화를 원한다면 아래 `scripts/init-db.ps1` 안내를 참고하세요.

1. 저장소를 내려받거나 복제합니다.
2. `index.html`을 웹 브라우저에서 엽니다.
3. 입양 문의 게시판은 `inquiry.html`을 열거나 홈페이지 내비게이션에서 **입양 문의 게시판**을 선택합니다.
4. 회원 화면은 내비게이션의 **회원가입** 또는 **로그인**을 선택합니다.

또는 프로젝트 폴더에서 간단한 로컬 서버를 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000>으로 접속합니다.

## SQLite 로컬 데이터베이스

SQLite CLI 없이 시작하려면 PowerShell에서 프로젝트 폴더로 이동한 다음 공식 SQLite 도구를 내려받고 DB를 초기화합니다.

```powershell
cd C:\Users\충남TP10\Desktop\adoption
.\scripts\init-db.ps1 -DownloadSqlite
```

스크립트는 SQLite 공식 Windows x64 CLI ZIP을 내려받고 WinGet 패키지 매니페스트의 SHA-256과 대조한 뒤 프로젝트의 `tools\sqlite\`에 설치합니다. 데이터베이스는 `data\adoption.db`에 생성되며, 아래의 단일 테이블을 준비합니다.

- `adoption_inquiries`: 문의 분류, 제목, 작성자 별명, 본문, 작성일, 조회수
- 유효한 문의 분류와 입력 길이를 SQLite `CHECK` 제약으로 검사
- 작성일 기준 목록 조회를 위한 인덱스

DB 파일과 로컬 SQLite 실행 파일은 `.gitignore`에서 제외됩니다. 데이터베이스를 직접 확인하려면:

```powershell
.\tools\sqlite\sqlite3.exe .\data\adoption.db ".schema adoption_inquiries"
```

> **현재 단계의 한계:** DB와 테이블만 만들었으며, 홈페이지 게시판은 아직 SQLite에 연결하지 않았습니다. 실제 DB 저장에는 API 서버와 입력 검증·접근 제어가 필요합니다.

## 파일 구성

```text
adoption-website/
├── index.html   # 메인 페이지 및 입양 동물 목록
├── style.css    # 공통 색상, 레이아웃, 반응형 스타일
├── script.js    # 예시 동물 데이터, 검색·필터 및 메인 화면 상호작용
├── inquiry.html # 입양 문의 게시판, 글쓰기·상세 보기 화면
├── inquiry.css  # 게시판 및 글쓰기 화면의 반응형 스타일
├── inquiry.js   # 게시글 검색·필터·작성·삭제와 브라우저 저장
├── signup.html  # 회원가입 화면 시안
├── login.html   # 로그인 화면 시안
├── auth.css     # 회원가입·로그인 공통 스타일
├── schema.sql   # SQLite 문의 게시글 단일 테이블 스키마
├── scripts/
│   └── init-db.ps1 # SQLite CLI 확인·설치와 DB 초기화
├── data/        # 로컬 SQLite DB 파일 (.gitignore 처리)
└── tools/       # 프로젝트 로컬 SQLite CLI (.gitignore 처리)
├── robots.txt   # 협조적인 크롤러에 사이트 페이지 접근 허용을 알리는 규칙
├── sitemap.xml  # 크롤러에 사이트의 대표 URL을 안내하는 사이트맵
└── README.md    # 프로젝트 설명과 실행 방법
```

54 | `robots.txt`는 사이트 루트의 `/robots.txt`, 사이트맵은 `/sitemap.xml` 경로에서 제공되어야 합니다. 현재 GitHub Pages는 이 저장소에서 활성화되어 있지 않으므로 공개 사이트 주소는 아직 설정되지 않았습니다. 사이트맵에는 메인 페이지와 입양 문의 게시판 URL 항목을 추가했습니다. 배포 시 `sitemap.xml` 안의 `REPLACE-WITH-YOUR-DOMAIN`을 실제 도메인으로 바꾸고, `robots.txt`에 `Sitemap: https://실제-도메인/sitemap.xml`을 추가해 주세요. `robots.txt`는 공개 사이트의 크롤링 안내일 뿐이며 접근을 강제하거나 제한하는 보안 수단은 아닙니다.

## 기술 스택

- HTML5
- CSS3 (Grid, Flexbox, 반응형 미디어 쿼리)
- Vanilla JavaScript (별도 라이브러리 없이 동작)
- Google Fonts: DM Sans, Noto Sans KR
- 동물 예시 이미지: Unsplash 원격 이미지
- 게시판 데이터: 브라우저 `localStorage` (현재 기기에만 저장되는 시연용)
- 게시글은 서버로 전송되지 않으므로 다른 기기·브라우저의 방문자와 공유되지 않습니다. 실제 커뮤니티 운영에는 서버·데이터베이스·인증 및 개인정보 보호 정책이 필요합니다.

## 실제 입양 서비스로 확장할 때

- 신뢰할 수 있는 공공 동물보호·보호소 데이터 API를 연결하고 공고 정보를 최신 상태로 관리합니다.
- 보호소별 위치, 연락처, 입양 조건 및 공고 출처를 정확하게 표시합니다.
- 상담 신청을 안전하게 저장·전달할 백엔드, 접근 통제 및 개인정보 처리 절차를 마련합니다.
- 서버 측 입력 검증, 오류 처리, 개인정보 보관·삭제 기준과 개인정보 처리방침을 적용합니다.
- 외부 이미지 사용 조건과 이미지 대체 텍스트를 점검합니다.
